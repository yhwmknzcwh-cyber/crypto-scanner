Step 14.2 iPad Structure Engine. 기존 MA/MACD/ATR/다중 시간대 방향·과열/눌림/재가속 엔진에, 이번 강의에서 자동화 가능한 구조만 추가했습니다. 실제 자동진입은 이제 Context → Location → Liquidity/Event → Confirmation → 구조적 SL/TP → 실제 R:R Gate를 통과해야 READY가 됩니다. FVG·OB, Swing High/Low, BOS/CHOCH, Liquidity Sweep/Fakeout, Equal High/Low, Wick 기반 허용오차 채널, S/R 성격의 리테스트 위치, Triangle Compression을 계산합니다. '스마트머니가 일부러 손절을 터뜨린다' 같은 의도 추정, 완벽한 평행채널 강제, 뉴스 첫 움직임은 항상 Fakeout이라는 주장은 규칙에 넣지 않았습니다. 채널 돌파 자체를 추격하지 않고, 구조 확인과 R:R이 확보될 때만 진입합니다. 가상매매 테스트용이며 실계좌 주문 기능은 없습니다.
