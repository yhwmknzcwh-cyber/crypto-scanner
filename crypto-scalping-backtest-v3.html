Crypto 5M Scalping Backtest V3

BTCUSDT · ETHUSDT / 4개 전략 × 시장가/지정가 진입 비교

준비. Bybit 5분봉 데이터를 직접 내려받아 4개 전략을 같은 조건으로 비교합니다.

A · EMA20/50 Pullback

EMA20 > EMA50(또는 반대) 추세. 시장가=확인봉 다음 시가, 지정가=신호 시점 EMA20 가격. 청산은 EMA20 반대 종가 이탈/시간청산.

B · Breakout + First Retest

직전 20봉 고/저 돌파 후 첫 Retest. 시장가=Retest 확인 후 다음 시가, 지정가=돌파 레벨. TP는 이전 Range 폭 0.5배 확장.

C · Range False Break

직전 20봉 Range Wick 이탈 후 복귀. 시장가=다음 시가, 지정가=깨졌던 Range 경계. 50%는 Range 중간, 50%는 반대편 경계.

D · Daily VWAP Pullback

UTC 일봉 VWAP 방향과 가격 위치가 일치할 때 VWAP Pullback 진입. TP는 당일 VWAP ±1 표준편차 밴드.

V3 비교 규칙
4개 전략 각각을 시장가 진입과 Post-Only형 지정가 진입 두 방식으로 비교합니다. 시장가는 신호 확인 후 다음 봉 시가에 진입하며, 진입·청산 모두 Taker 비용과 Slippage를 반영합니다. 지정가는 전략별 자연스러운 가격(EMA20 / 돌파레벨 / Range 경계 / VWAP)에 주문을 두고 기본 3개 봉 동안만 유효합니다. 그 기간에 가격이 지정가를 터치하지 않으면 미체결로 폐기합니다. 지정가 진입은 Maker 비용, 청산은 보수적으로 Taker 비용을 적용합니다. 같은 5분봉에서 지정가 체결과 SL이 모두 가능하면 보수적으로 체결 후 SL로 처리합니다. 결과에는 신호수·체결수·체결률까지 표시해, 지정가의 낮은 비용과 미체결 손실을 동시에 비교합니다.
